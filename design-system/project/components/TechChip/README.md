# TechChip

A pill naming one technology, used in wrapping rows inside glass cards and project cards.

`glass-5` fill and border, `radius-full`, 14px text, padding 6px × `space-3`, `space-2` gaps. Hover: scale 1.05–1.08, lift 4px, `primary` 50% border, `primary` 10% fill, `glow-violet`. The consumer supplies the label only (the tool's own casing: "PyTorch", "Scikit-learn"). Chips are not buttons; do not attach actions.
