# ContactLink

A contact row: a 48px glass icon circle (`glass-5` fill, `glass-10` border, `radius-full`) beside a `muted-foreground` label and a medium `foreground` value at 18px.

Hover turns the text `secondary` and the circle `primary` 20% with a 50% border. The consumer supplies a 20px icon, the label ("Email Me", "Location") and the value, plus `href` (`mailto:`, map link).
