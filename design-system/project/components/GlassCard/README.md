# GlassCard

The house surface: a translucent panel over the glowing navy ground — `glass-5` fill and border, `blur-sm` backdrop, `radius-2xl`, `space-6` padding (`space-8` for feature cards).

Heading: `card-heading` with a 24px `secondary` icon. Lists use `muted-foreground` text with 6px `primary` bullets. On hover the border turns `secondary` at 50%. Place it on `background` or a section band; it needs a glow or gradient behind it to read as glass.
