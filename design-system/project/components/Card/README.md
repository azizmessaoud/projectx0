# Card

The solid shadcn Card for dense content: `card` fill, 1px `border`, `radius-xl`, `shadow-sm`.

Parts: header (`space-6` padding, 6px gap) with a title (600, tight tracking) and a description (14px `muted-foreground`), then content (`space-6`, no top padding) and an optional footer. Prefer GlassCard for portfolio sections; use Card where the background must be opaque.
