# SectionHeading

Opens every page section: a white `section-title` (30px, 48px from md) led by one emoji, then a `body-lg` intro in `muted-foreground`, max width `container-2xl`, with `space-12` below.

The consumer supplies the emoji, a Title Case title and one sentence-case line. The emoji spins in once on scroll; the block fades and rises in.
